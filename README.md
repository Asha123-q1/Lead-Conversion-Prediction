# Lead Conversion Prediction

Predicts which leads are most likely to convert, so sales teams can focus on high-value leads.

## Tools
Python, Pandas, Scikit-learn, XGBoost

## Approach
- Data preprocessing and exploratory data analysis
- Feature engineering ahead of model training
- Compared Logistic Regression, Random Forest and XGBoost using accuracy, precision, recall and F1-score

## Result
XGBoost performed best with 97.95% accuracy and was recommended for deployment.
